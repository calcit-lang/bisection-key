# Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

## 中文

- 将 Calcit CLI 与 `@calcit/procs` 从 0.13.64 同步升级到精确版本 0.13.77。
- 保持 bisection key API、排序语义以及现有静态分析预算不变。
- 使用 strict Caps、toolchain verification、native、JS 与 WASM 测试验证升级。

## English

- Upgrade the Calcit CLI and `@calcit/procs` together from 0.13.64 to the exact 0.13.77 release.
- Preserve the bisection key API, ordering semantics, and existing static-analysis budgets.
- Validate the upgrade with strict Caps, toolchain verification, and native, JS, and WASM tests.
