# Upgrade Calcit 0.13.64 / 升级 Calcit 0.13.64

## 中文

- 将 Calcit CLI 与 @calcit/procs 从 0.13.40 同步升级到精确版本 0.13.64。
- 将 setup-calcit 从提交 hash 改为稳定的 v1 tag，并使用 strict Caps 与 toolchain verification 阻断依赖版本漂移。
- 为 default entry 建立零 dynamic-method 门禁，并将 test entry 的 18 个存量调用设为不可增长的显式预算。
- 保持 bisection key API 与排序语义不变，同时弱化 README 中的语言比较，直接介绍 Calcit 模块自身。
- 通过 native、JS、WASM、文档示例与静态质量 baseline 回归。

## English

- Upgrade the Calcit CLI and @calcit/procs together from 0.13.40 to the exact 0.13.64 release.
- Replace the setup-calcit commit hash with the stable v1 tag, and use strict Caps plus toolchain verification to prevent dependency version drift.
- Enforce zero dynamic method dispatch for the default entry and record the test entry's 18 existing calls as an explicit non-increase budget.
- Preserve the bisection key API and ordering semantics while making the README Calcit-centric instead of language-comparison-centric.
- Cover native, JS, WASM, documentation examples, and the static quality baseline.
